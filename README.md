### Projects

- [Let's Chat · Matrix Messaging](https://github.com/TolkmisLK/mutual_chat) — Standalone or embedded encrypted chat with session recovery, retrying failed messages with the original transaction, device number comparison, and local search. [Getting started](https://github.com/TolkmisLK/mutual_chat#readme) · [Windows / Web preview](https://github.com/TolkmisLK/mutual_chat/releases/tag/v0.1.0-preview.2). Requires a Matrix server and account; contact identity verification and initial backup setup remain unfinished.
- [Pass Along · LAN File Transfer](https://github.com/TolkmisLK/Mutual_transfer) — Share a file workspace with resumable uploads, explicit upload cancellation, hash verification, and paired-device management. [Illustrated guide](https://github.com/TolkmisLK/Mutual_transfer/blob/main/docs/QUICKSTART.md) · [Windows service](https://github.com/TolkmisLK/Mutual_transfer/releases/tag/windows-v0.1.0-preview.1) · [Android preview](https://github.com/TolkmisLK/Mutual_transfer/releases/tag/android-v0.1.1-preview). Browser and Android clients connect to a self-hosted service; real Wi-Fi interruption and cross-device compatibility still need acceptance testing.

- [Device Companion · Android Tools](https://github.com/TolkmisLK/adb-device-desk) — Connect Android devices on Windows, install an APK across selected devices, stop and continue the remaining queue, capture screens, and export logs. [Guide](https://github.com/TolkmisLK/adb-device-desk#readme) · [Windows preview downloads](https://github.com/TolkmisLK/adb-device-desk/releases/tag/v0.1.0-preview.5). Requires ADB and an authorized Android connection.

- [Relay · Reliable Webhook Delivery](https://github.com/TolkmisLK/webhook-delivery-platform) — Sends events to HTTP endpoints, retries failed deliveries, and records each attempt with filtered delivery-history pages. [Docker Compose walkthrough](https://github.com/TolkmisLK/webhook-delivery-platform/blob/main/docs/demo.md) · [Source preview](https://github.com/TolkmisLK/webhook-delivery-platform/releases/tag/v1.1.0-preview.1). Receivers must handle duplicate events.
- [Call Trace · MCP Diagnostics](https://github.com/TolkmisLK/mcp-trace-lab) — Record MCP stdio traffic and inspect tool calls, errors, and timing. [Run the example](https://github.com/TolkmisLK/mcp-trace-lab/blob/main/docs/demo.md). [Installable CLI preview](https://github.com/TolkmisLK/mcp-trace-lab/releases/tag/v0.2.0-preview.2), including separate protocol/tool failure counts and a CI failure exit code; review traces for sensitive content before sharing.

- [Site Starter · Personal Page Template](https://github.com/TolkmisLK/TolkmisLK.github.io) — Edit one configuration file to publish a bilingual page with themes, interactive elements, a project index and shareable links. ### 项目

- [聊聊 · 即时通信](https://github.com/TolkmisLK/mutual_chat) — 基于 Matrix 的加密聊天，可独立运行或嵌入应用，支持会话恢复、失败消息原事务重试、设备数字核对和本地搜索。[开始使用](https://github.com/TolkmisLK/mutual_chat#readme) · [Windows / 网页预览包](https://github.com/TolkmisLK/mutual_chat/releases/tag/v0.1.0-preview.2)。需要 Matrix 服务与帐号；联系人身份验证和首次备份仍未实现。
- [随传 · 局域网文件传输](https://github.com/TolkmisLK/Mutual_transfer) — 共享文件空间，支持断点续传、取消上传后的清理、摘要校验和配对设备管理。[图文教程](https://github.com/TolkmisLK/Mutual_transfer/blob/main/docs/QUICKSTART.md) · [Windows 服务包](https://github.com/TolkmisLK/Mutual_transfer/releases/tag/windows-v0.1.0-preview.1) · [Android 预览版](https://github.com/TolkmisLK/Mutual_transfer/releases/tag/android-v0.1.1-preview)。浏览器和安卓客户端连接自建服务；真实 Wi-Fi 中断与不同设备的兼容性仍需验收。

- [机伴 · 安卓设备助手](https://github.com/TolkmisLK/adb-device-desk) — 在 Windows 上连接设备、批量安装 APK、停止并继续未执行目标、截图和导出日志。[使用教程](https://github.com/TolkmisLK/adb-device-desk#readme) · [Windows 预览版下载](https://github.com/TolkmisLK/adb-device-desk/releases/tag/v0.1.0-preview.5)。需要 ADB 和已授权连接的安卓设备。

- [信使 · Webhook 可靠投递](https://github.com/TolkmisLK/webhook-delivery-platform) — 将事件推送到 HTTP 接口，失败后重试，并在网页控制台按状态和接收地址筛选历史结果。[Docker Compose 演示](https://github.com/TolkmisLK/webhook-delivery-platform/blob/main/docs/demo.md) · [源码预览版](https://github.com/TolkmisLK/webhook-delivery-platform/releases/tag/v1.1.0-preview.1)。接收方需要处理重复事件。
- [循迹 · MCP 调用排障](https://github.com/TolkmisLK/mcp-trace-lab) — 记录 MCP stdio 请求与响应，查看工具调用、错误和耗时。[运行示例](https://github.com/TolkmisLK/mcp-trace-lab/blob/main/docs/demo.md)。[命令行预览包](https://github.com/TolkmisLK/mcp-trace-lab/releases/tag/v0.2.0-preview.2)可直接安装，区分协议错误和工具失败，并支持 CI 失败退出码；分享追踪文件前请检查敏感内容。
